🧪 请求样本回放校验

每条样本填写旧版操作的方法与路径模板（如 POST / /pets/{id}）、 Content-Type 与 JSON 请求体；新版按相同方法和路径模板查找操作， 操作或媒体类型消失视为新版拒绝。校验覆盖 type / required / enum / properties / items / allOf 与本地 $ref（循环引用安全终止）；无法解析的引用或范围外约束（format/pattern/oneOf/…） 标为无法判定、不计风险。旧版操作不存在 / JSON 格式错误逐条报错；旧版拒绝的样本不计风险。 结果只供本次查看，不改变审查结论。

语义兼容性规则

判定按两个方向独立进行：请求方向关注"客户端原本合法发送的内容是否被收紧"； 响应方向关注"客户端原本可能收到的承诺是否被改变"。因此同一类 schema 变化在两个方向上结论可能相反。
